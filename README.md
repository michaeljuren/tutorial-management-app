# Tutorial Management Application

A full-stack application for managing tutorials. The Angular frontend provides a user interface for creating, browsing, searching, editing, and deleting tutorials. A Spring Boot REST API persists tutorial data in MySQL.

## Features

- Create, list, view, update, and delete tutorials
- Search tutorials by title
- Filter tutorials by published status through the API
- Store tutorial data in MySQL, with Flyway database migrations

## Technology stack

| Area | Technologies |
| --- | --- |
| Frontend | Angular 19, TypeScript, RxJS, Bootstrap 5 |
| Backend | Java 17, Spring Boot 3.4, Spring Data JPA, Maven |
| Database | MySQL 8, Flyway |

## Prerequisites

- Java Development Kit (JDK) 17
- Node.js and npm (Node.js 18.19.1 or later for Angular 19)
- Docker or Podman to run MySQL locally, or an existing MySQL 8 server

The backend includes the Maven Wrapper, so a separate Maven installation is not required.

## Getting started

Run the database, backend, and frontend in separate terminals.

### 1. Start MySQL

From any directory, create and start a local MySQL container:

```sh
docker run --name tutorials-mysql \
  -e MYSQL_ROOT_PASSWORD=root \
  -e MYSQL_DATABASE=tutorials \
  -p 3397:3306 \
  -d mysql:8.1
```

To use Podman, replace `docker` with `podman`. If the container already exists, start it with `docker start tutorials-mysql` (or `podman start tutorials-mysql`).

The backend is configured to connect to `jdbc:mysql://localhost:3397/tutorials` as `root` with password `root`. If your database uses different settings, update `backend/src/main/resources/application.properties` and the Flyway Maven plugin configuration in `backend/pom.xml`.

### 2. Run the backend

From the `backend` directory, start the Spring Boot application with the Maven Wrapper:

```sh
# Windows PowerShell
.\mvnw.cmd spring-boot:run

# macOS/Linux
./mvnw spring-boot:run
```

Flyway applies the SQL migrations at application startup. The API is served at `http://localhost:8080`.

To build and test the backend:

```sh
# Windows PowerShell
.\mvnw.cmd clean verify

# macOS/Linux
./mvnw clean verify
```

### 3. Run the frontend

From the `frontend` directory, install dependencies and start the Angular development server:

```sh
npm install
npm start
```

Open [http://localhost:4200](http://localhost:4200). The frontend calls the backend at `http://localhost:8080/api/tutorials`; make sure the database and backend are running.

## API

All endpoints are prefixed with `/api` and are available on the backend's default port, `8080`.

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/api/tutorials` | List all tutorials |
| `GET` | `/api/tutorials/{id}` | Get a tutorial by ID |
| `POST` | `/api/tutorials` | Create a tutorial |
| `PUT` | `/api/tutorials/{id}` | Update a tutorial |
| `DELETE` | `/api/tutorials/{id}` | Delete a tutorial |
| `DELETE` | `/api/tutorials` | Delete all tutorials |
| `GET` | `/api/tutorials/published` | List published tutorials |
| `GET` | `/api/tutorials/title/{title}` | Search tutorials by title |

A tutorial has the following fields:

```json
{
  "id": 1,
  "title": "Introduction to Java",
  "description": "Learn the basics of Java programming.",
  "published": true
}
```

The `id` is generated by the database when a tutorial is created. For `POST` and `PUT` requests, send a JSON tutorial object with the relevant `title`, `description`, and `published` values.

## Development

### Frontend

Run these commands from `frontend/`:

```sh
npm run build   # Production build
npm test        # Unit tests
npm start       # Development server
```

The production build is written to `frontend/dist/`.

### Backend

Run these commands from `backend/`:

```sh
.\mvnw.cmd clean verify       # Windows: compile and run tests
.\mvnw.cmd spring-boot:run    # Windows: run the application
```

On macOS/Linux, use `./mvnw` in place of `.\mvnw.cmd`.

Flyway migration scripts are stored in `backend/src/main/resources/db/migration/`.
